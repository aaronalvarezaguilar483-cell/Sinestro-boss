# Sinestro Boss (Fabric 1.20.1)

Jefe Sinestro para el addon A New Corps. Requiere: Fabric Loader, Fabric API y A New Corps (+ Palladium, GeckoLib, KubeJS, Trinkets que ese addon ya pide).

## Compilar sin PC (GitHub Actions)
1. Crea un repositorio en GitHub y sube TODO el contenido de esta carpeta (incluida la carpeta oculta .github).
2. Ve a la pestaña Actions -> "build" -> Run workflow (o se ejecuta solo al subir).
3. Al terminar, abre la ejecución y descarga el artefacto "sinestro_boss": dentro está el .jar.
4. Pon el .jar (el que NO termina en -sources) en la carpeta mods.

## Cómo usarlo
- Huevo generador: pestaña de huevos del creativo.
- Tótem del Miedo: se craftea con 8 bloques de oro + 1 estrella del Nether; clic derecho en un bloque para invocar.
- No funciona en dificultad Pacífica (los mobs hostiles desaparecen).
